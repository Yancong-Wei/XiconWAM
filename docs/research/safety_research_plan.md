# XiconWAM：预测避险与任务恢复研究方案

日期：2026-11-06。状态：研究设计与离线标注工具；未训练安全模型、未接入控制、未验证 GPU/仿真成绩。目标同时包含原版 RoboDojo Sim 打榜与可独立评估的安全贡献。

## 判断与论文问题

World model + action model + small safety model 技术上可行，但三模块组合本身不构成新颖贡献。建议研究问题：**在大模型异步推理期间，小模型如何提前规避危险，同时把系统带到大模型可恢复任务的状态？**

暂定英文描述：Intervention-Aware World–Action Models with Recoverability-Guided Safety Reflexes。不是已验证的新方法名称或论文结论。

重点检验三条假设：

1. 未来表征 + 当前观测 + 待执行动作比纯当前观测检测更早识别危险；必须与等规模的无 world-feature 小模型比较。
2. 带恢复价值的小模型比仅避碰/停止更容易在干预后完成任务；必须控制数据量、参数量、调用预算。
3. 干预后状态重建、旧计划作废和恢复训练，比简单再次调用原策略更能减少反复碰撞与接管振荡。

若只有代码集成、普通风险头、固定阈值、CBF 拼接，论文力度不足。当前查重为摘要/项目页级，未完成所有近邻全文及代码复现，不能保证新颖性。

## 三个模型的具体职责

### W：慢速世界模型

输入当前观测/必要历史、指令、实际执行动作；输出短期未来 latent 与目标/进度上下文。优先复用 XiconWAM 视觉分支，避免新增第二个视频大模型。

当前 MoT 的 video queries 不读取 action tokens，因而当前 W 只能作为视觉未来先验。若声称“比较不同避让动作的后果”，必须补动作条件预测：先做小型 action-conditioned latent transition 或 risk scorer，并在同状态不同动作的真实模拟器分支上验证排序。不能假设生成的视频就是任意候选动作的物理后果。

### A：任务动作模型

复用 action expert，生成名义 14D 绝对关节目标 chunk。第一版冻结 W/A，先训练小模型以隔离增益来源。随后少量混合干预后恢复数据训练 A；防止正常任务能力遗忘。夹爪与机械臂坐标单位不同，不用统一标量残差界限。

### S：快速预测避险与恢复模型

建议起点是小视觉编码器 + 时序模块 + 多头网络，约 5–30M 参数仅作为工程预算，最终由延迟实验决定。输入：最新三相机特征、q/估计dq、最近实际动作、剩余名义 chunk、W 的缓存上下文、缓存年龄与 intervention 标记。不能只读取慢模型旧特征，否则看不到新危险。

输出：

- 未来不同 horizon 内的违规风险/首次违规分布，并给出风险类型；不是泛化的任务失败概率。
- 短程避让残差或少量修正候选（初始 2–4 动作步，属实验起点）。
- 候选终态的任务恢复价值：在固定接续策略与预算下，能否无违规完成任务。

可以一个 S 共享主干，用 risk、correction、recoverability 三个 head；先分开训练/验收，再联合。小模型输出仍需独立的关节、速度、工作空间/几何约束检查。几何检查的作用限于已建模约束；离散点无碰撞不代表扫掠路径无碰撞，端点合法也不代表控制动态可行。

## 执行与交接

普通模式：A 提名义 chunk，S 用新观测持续检查，只执行已许可的短前缀。风险提前量必须大于感知、S 推理、通信、动作生效和制动总延迟；达不到就不能声称能及时避险。

干预模式：S 提短期修正，经独立约束检查后执行；禁止双臂独立修正导致互撞，必须检查整个机器人和抓持物体。推、插、抓等正常接触应在任务相位与接触对允许集合内，不能把所有接触都禁掉。

重规划：立即给原计划标记失效；W/A 使用干预后的新观测和实际动作重新预测。生成期间 S 继续监测/控制。新计划携带 observation timestamp、plan version 与 intervention epoch；旧版本结果不允许晚到后覆盖当前安全动作。交回前检查当前状态差、约束与短前缀，不盲接旧 chunk。

无可行修正/信息过期时：使用经验证的退避或制动策略，或结束该次任务；保持当前关节位置并非在所有接触/抓持状态下安全。报告停止率、任务失败率，不能靠不动获得安全性结论。

当前新增 eval/XPolicyLab_core/policy.py 会一次返回 replan_steps 个动作。若模拟器在执行整个返回 chunk 时不回传新观测，S 放在一次请求内部不能监控中途新危险。先用官方支持的短动作返回周期，在策略服务器内维护 W/A 缓存；完整异步接管需确认客户端协议，不能私改官方动力学、动作预算与成功判据。

## 数据与训练：先证明值得做

1. 固定一个可复现的 XiconWAM baseline；采集名义成功、自然失败与开发场景扰动轨迹。
2. 安全事件按预声明的规则标注：禁止接触对、机器人自碰、非目标物碰撞/危险移动、关节/速度违规、物体越界。任务失败与安全违规分开。碰撞冲量阈值、允许接触相位、区域边界必须来自任务定义/控制约束并在训练前记录，不能为涨点事后调整。
3. 训练 S-risk：过去与当前输入预测未来事件；按 episode 划分，按未见任务/布局测试；时间截断和停止后的未知未来使用删失 mask，不作为安全负例。
4. 训练 correction/recoverability：在可复现开发状态上尝试名义动作、几何修正、学习修正。以真实仿真结果产生可行修正与后续完成标签；状态恢复必须覆盖物体、机器人、控制器及必要随机状态。无法精确恢复时用匹配重置并报告差异。
5. 小模型教师可用训练环境几何或仿真规划器，但最终学生只读提交允许的观测。仿真真值供离线标签/评价；带真值的 oracle 单独作为上界。世界预测不能自行给自己安全标签。
6. 补充干预后真实状态的恢复轨迹微调 A；不能仅把名义成功示范加噪后当成“恢复正确答案”。

初筛建议：选 4–6 个能稳定运行且确有安全相关失败的任务，如 stack_bowls、pack_objects_into_box、insert_tubes、plug_in_charger、fill_pen_holder、organize_table；先检查失败录像。每任务约 30–50 次开发 rollout 只用于诊断正例覆盖。若安全事件不足，应添加独立研究扰动集；不要用大量安全正常帧掩盖无正例的问题。

首轮 go/no-go：真实提前量够不够？纯反应几何方案是否已足够？干预后是否能继续？新增 world 信息是否优于同规模无 world 分支？失败主要是记忆/语义时，安全模块对总榜收益可能有限，不把它当五维全能补丁。

## 打榜与论文的实验安排

原版 RoboDojo：固定官方任务、计分、随机化与原生次数，评测五维 Score/SR，报告三 seed。全模型作为一个策略接入，公开 checkpoint/版本与组件；加入规划/修正可能影响 track 分类，最终以官方审核为准，不能自行断言属于纯 WAM 轨道。

安全研究集：单独标记 RoboDojo-derived safety stress suite，包含动态杂物、动作延迟、遮挡或抓持偏移等预定义扰动。不能把这里的成绩当官方榜单。另用 SafeLIBERO 等公开安全基准检验可迁移性，先核对其输入/机器人接口成本；并非本轮已接入。

核心组：A0 原基线；A1 最佳固定短chunk；A2 几何filter；A3 S风险+停止/重规划；A4 S风险+局部修正；A5 加恢复价值；A6 加干预后重规划/恢复训练。对 A6 再做去掉 world特征、去掉新观测、去掉恢复标签、等参数等数据等调用预算对照。必需近邻是 SAFE、AEGIS/VLPSA、FFDC/TempoWAM、Route-Guided Repair；WASP 作概念/方法比较，任务域不同不能直接混列数值。

指标：官方 SR/Score；SafeSuccess=P(完整成功且全程无预定义违规)；违规 episode 率、违规步率/暴露时间；干预后恢复成功率及其分母；风险 AUCPR、固定误报下召回与提前量；无可行解/停止比例；action deviation、p50/p95端到端延迟、W/A/S调用数。报告安全—成功—计算 Pareto，不能只报安全率。

异步优势需要在真实墙钟延迟下验证。若仿真暂停等待推理，就只能证明仿真控制收益，无法证明在大模型等待期间能躲避动态障碍。单独做预声明的延迟实验并区分官方结果。

## 近邻工作与边界（已读原始摘要/项目页）

- [SAFE, NeurIPS 2025](https://arxiv.org/abs/2506.09937)：内部特征预测失败；风险头本身不新。
- [AEGIS / VLSA](https://vlsa-aegis.github.io/)：CBF约束层与SafeLIBERO；加CBF本身不新。
- [VLPSA](https://arxiv.org/abs/2609.22462)：全身和抓持物体安全过滤；不能只保护末端。
- [WASP, IJCAI 2026](https://ijcai.org/proceedings/2026/409)：世界预测风险和任务退化，规划短程残差；“预判+修正”已有强近邻。
- [Route-Guided CBF-QP Repair](https://arxiv.org/abs/2611.01713)：围绕障碍产生entry-exit-rejoin引导；“躲开后回任务轨迹”已有近邻。
- [FFDC](https://arxiv.org/abs/2605.06222)、[TempoWAM](https://arxiv.org/abs/2608.09492)：预测验证/进度驱动重规划。
- [CA3C](https://arxiv.org/abs/2610.07949)：世界模型候选后果一致性选执行长度；候选未来比较也不够独立。
- [AHA-WAM](https://arxiv.org/abs/2606.09811)：异步世界/动作与缓存；异步双速本身不新。
- [Causal-History Recovery](https://arxiv.org/abs/2609.18016)：自回归WAM失败后的历史前缀恢复、状态重建与假设验证；“重建旧世界预测”也有近邻。当前XiconWAM不是该类长期自回归历史实现，不能直接套用其KV恢复结论。
- [RAYA](https://raya-control.github.io/)：学习有限时域恢复裕度并调度控制权，用于飞行器与车辆；恢复性监督本身也不是空白。需要区分保持动力学安全可恢复性与双臂操作避险后完成指定任务的可恢复性。

更有希望的贡献是：**以任务可恢复性监督快速安全干预，并针对干预导致的世界预测失效，联合训练重规划与交接。** 必须用消融证明优于现有修正+再调用；如果没有独立增益，就降级为工程方案，不强行包装新算法。

## 已落地的辅助工具

`scripts/research/safety_labels.py` 是纯标准库离线工具，不加载模型、不连接机器人、不修改执行动作。每行一个 episode JSON：

```json
{"episode_id":"run1/taskA/seed0/0","task":"taskA","complete":true,"task_success":false,"events":[[],[],["forbidden_contact"],[]]}
```

events[t] 必须是执行 action[t] 后对应时间区间的全部已检测违规，空列表表示该区间已观测且无违规，不能把漏采样写为空列表。输入必须从 episode 起点连续覆盖；complete=true 表示已记录到协议终止，提前安全停止应作为任务未完成而非成功。中断日志用 complete=false、task_success=null。事件类型由收集器判定；本工具不能检测接触，也不能验证输入语义。

```bash
python scripts/research/safety_labels.py /path/to/events.jsonl --output /tmp/safety-report.json --horizons 4 8 16 32
python -m unittest discover -s tests -p test_safety_labels.py -v
```

输出按任务 SR、SafeSuccess、违规 episode/步率、完整覆盖率和每决策时刻未来违规标签。未来窗口不足且未见违规标为 null；已观测违规可标正例。标签仅代表日志中实际执行策略的未来，不能直接解释为“坚持原chunk不重规划”的反事实风险；后者需要固定候选执行的分支数据。工具不输出官方总分、不训练风险头，也不等价于安全控制系统。
