# XiconWAM V2：前后效果与 RA-L 审稿判断

调研日期：2026-11-09（北京时间）。对象：引用聊天最后确定的 Wan2.2-5B + MoT + DINOv3 + 循环状态记忆 + 动作结果预测 + 未来语义监督。资源：4～8 张 H20。

结论：值得作为 RA-L 候选方向投入，但目前仍是设计，不能据此判断已经达到录用水平。若仅以组件组合和 RoboDojo 总分提升成文，模拟审稿意见为弱拒；若明确证明执行反馈修正状态记忆的独立价值，并有严谨闭环实验，则有合理投稿基础。这里的判断是研究建议，不是录用概率。

## 1. 证据状态

- 已读取引用聊天 `01a1bf19-6138-79c2-a98a-ecdfc48e7b44`，并核对本地设计、MoT 注意力、训练状态输入和评测适配器。
- 当前 `Policy.update_obs` 只保存最新观测；`get_action` 使用当前三相机、状态和语言，每次返回动作短前缀。因此基线已有重新观察与重规划的闭环，不应描述为开环策略。
- `objective.py` 取窗口首个 proprio 状态；当前 MoT 视频 queries 不读取 action tokens。联合生成视频和动作，不等于视频分支能模拟任意候选动作的后果。
- V2 持久记忆及动作结果预测仍是设计；本轮没有训练、闭环成绩或真机验证。不能给出真实的提分幅度。
- 基线没有跨请求持久记忆，因此不能把“旧记忆污染”说成已证实的基线失分机制；加入记忆后才需要进一步检查这一问题。

## 2. 改前与改后究竟有什么变化

### 当前版本

每次看到当前图像、关节状态和指令，联合预测未来视频与 32 步动作，执行短前缀，再获取新图像。跨请求没有持久状态。不同历史在当前图像相似时，策略难以区分最初目标、已经完成的步骤及过去发生的事件；这只是结构性风险，尚不是已定位的全部失败原因。

### V2 候选版本

1. 当前三相机也进入冻结 DINOv3，产生空间条件；视频原支路保留。
2. 首帧 anchor 保留初始线索；循环记忆压缩交互历史。
3. 结果预测器依据上一状态、上一观测、实际执行的动作前缀与时间差，预测新观测的特征。
4. 新观测与预测之间的残差参与更新记忆；世界和动作分支读取更新后的记忆。
5. 连续多窗口训练学习记忆更新；未来语义头在因果输入下预测未来冻结教师特征。

它增加了“跨决策状态估计与执行反馈更新”的能力接口。接口存在，不代表模型已经学会对象跟踪、阶段回退、可信状态估计或恢复策略。

### 各组件的可期待效果与边界

- **DINO 当前条件**：可能改善物体与背景区分、局部空间表征和外观扰动鲁棒性；不会自动提供度量几何、接触状态或语言推理。4×4 池化也可能丢失小目标和插入细节。
- **首帧 anchor**：有望保留“最初指定的是哪个物体、原来摆在哪里”等线索；不能充当永远正确的当前场景状态。
- **循环记忆**：有望改善遮挡、任务顺序与多步进度；也可能遗忘、积累错误或被策略忽略。随机单窗口训练不能替代连续记忆训练。
- **动作结果残差**：有望帮助识别“预期抓到但没有抓到”等执行偏离；相机运动、遮挡、光照及预测器本身的误差也会造成残差。残差不是失败概率。
- **未来语义监督**：有望把世界流容量导向控制有用的未来表征；辅助 loss 降低不代表闭环改善。必须验证动作分支确实利用了这些特征。
- **执行 10 步改 8 步**：增加观察频率，可能独立提高成功率，也会增加模型调用与墙钟成本。比较架构时双方必须使用相同前缀。

最有理由期待的收益集中在 Memory 和 Long-Horizon；部分 Generalization 可能获益。Precision 是否提升取决于特征分辨率、控制误差与时序；Open 推理不能由这组改动保证。以上均为待验证假设，不是本项目测得结果。

### 抓空例子：三层能力要分开

旧模型有可能根据新图像重新尝试，也可能继续名义搬运；不能预设它一定无视反馈。V2 希望依次做到：

1. 新图像与预测结果不一致，发现抓取可能未成功；
2. 把当前状态估计从“正在搬运”修正为“尚未抓住”；
3. 输出可成功重抓的动作。

预测器主要服务第一步，记忆更新服务第二步，恢复策略与训练覆盖服务第三步。前两步成功不能自动推出第三步成功。仅成功示范支持名义动作结果学习，对真实失败后的恢复监督不足。

## 3. 与近邻的重合：不能再以什么作为主贡献

以下来自原论文全文核对，不代表本轮已复现其代码或独立验证作者实验。

- [RM-WAM](https://arxiv.org/html/2610.15305)：短期视觉/长期事件记忆、反事实历史条件与效用门控；已经讨论陈旧信息、阶段错配、错误污染，并报告真实扰动下的状态重估收益。你的差异需要落在实际执行动作条件下的预测—观察修正机制，而非笼统“可靠记忆”。
- [AEM](https://arxiv.org/html/2606.12499)：视觉和动作历史交错编码，以掩码学习获得紧凑动作—效果记忆。因此动作历史、紧凑记忆或动作效果表征本身不足以构成新贡献。
- [AGRA](https://arxiv.org/html/2606.12217)：以冻结视觉编码器表征对齐世界—动作接口。DINOv3 支路与预测残差不是该方法的完全等价物，但升级教师、增加语义 loss 不能单独支撑新颖性。
- [Long-WAM](https://arxiv.org/html/2610.10528)：研究上下文长度和预训练形式的关系；增加历史不保证收益，也伴随推理成本。不能据此推出所有 WAM 都必须另做自回归预训练。
- [FaRe](https://arxiv.org/html/2609.18016)：自回归 WAM 的失败恢复，使用进度触发、可靠历史前缀重建和历史假设验证。说明“执行失败后修改历史以恢复”也是已有问题。你的固定大小递归状态与其因果 KV 缓存不同，不能直接套其污染机制或恢复实现。

## 4. 作为审稿人，我会提出的主要问题

### R1：方法目前仍可能等价于常规递归状态估计

根据动作预测，再根据观测纠正状态，是经典预测—校正思想。仅把预测残差拼成一个 token，再交给 Transformer，并没有自动产生新的学习算法。

可行的收窄方向：将实际执行动作产生的状态先验与新观测支持的修正显式区分，设计训练使状态修正确实改变后续决策。无关外观变化不应轻易抹除可靠历史，任务相关执行偏离则应能修正已失效的当前状态假设。无需把完整系统都改成符号对象模型，但应定义可测的状态属性，如是否抓持、目标位置、子目标是否完成。

这些只是候选机制要求，不是已经实现的新算法。若同参数普通循环更新器表现相同，应如实承认没有额外机制贡献。

### R2：没有证明失败来自状态估计

失败可能来自当前感知、精细控制、语言理解、动作归一化或延迟。需要以受控任务、held-out 状态探针和有限的诊断性状态替换，区分这些原因。模拟器特权状态可以用于离线标签和诊断，不能进入普通测试策略。

### R3：成功轨迹不足以验证失败恢复

需要真实 rollout 中的执行偏离与恢复经验，或足够说明泛化来源的无恢复监督实验。对历史做丢帧、陈旧增强不能模拟滑落后的物理状态和正确恢复动作。

### R4：改动太多导致贡献归因不清

DINO、历史、语义监督、学习率、骨干解冻、重规划频率与额外恢复数据都会带来收益。可以先集中实现完整版本，但投稿前仍须保留同数据、同历史、相同前缀、近似参数量与推理预算的关键对照。

### R5：代价和泛化证据不足

96 个额外条件 tokens 不是总成本的完整度量；DINO 三视角前向、连续窗口训练和更频繁重规划都需测量。报告 p50/p95 端到端延迟、单位任务调用数及完成时间。一个榜单的分数提升也不能证明跨场景恢复机制普适。

## 5. 最小但有说服力的证据组合

这不是 RA-L 官方实验清单，而是针对本方案的审稿建议。不做所有组件的排列组合。

### 必须区分的四个模型

- **B0：原 MoT**。统一数据划分、训练预算与执行前缀，得到可复现基线。
- **B1：MoT + DINO + 同样未来语义监督**。无跨请求记忆；分离感知与表征监督的收益。
- **B2：B1 + 普通循环记忆**。与完整方法读取同样历史、proprio 和实际动作，参数量尽可能匹配，但不使用预测—观察残差；训练/部署状态更新一致。
- **B3：完整执行反馈修正**。其余配方与 B2 相同，保留结果预测与残差更新。

B3 超过 B0 只能说明整体版本有效；B3 超过 B2 才支持新机制的独立作用。B2/B3 均采用同样连续多窗口训练、教师、恢复数据和重规划频率。必要时让 B2 也保留相同辅助预测 loss，只切断残差到记忆更新器的路径，以排除辅助训练正则化的解释。

另需一个有针对性的可靠记忆近邻（优先 RM-WAM）比较；若无可用代码，明确实现与原论文的差异，不把自建弱基线命名为完整复现。可在同一骨干上实现其选择性记忆原则作额外对照。

### 三类互补评测

1. **RoboDojo 原协议**：报告五维 Score / SR 和逐任务结果，遵守原生 rollout 预算。三个独立训练 seed 是建议起点；报告区间，区分训练 seed 与环境 seed。依协议评测，不能只挑涨分任务。
2. **受控机制测试**：开发阶段选 4～6 个相关任务，预定义抓空、轻微滑落、目标位移与短时遮挡；另加光照/背景变化作无关扰动对照。保留未见扰动强度与时机。额外压力测试与官方结果分开，且每种方法有相同恢复步数/时间预算。
3. **迁移证据**：独立的记忆/操作基准或真机任务验证相同结论。若主张真实机器人闭环恢复，建议加入 2～3 类受控真机任务，每方法每条件约 20～30 次作为预算起点，按置信区间宽度调整；这不是统计充分性保证，也不是 RA-L 硬性门槛。

### 除 SR 外最重要的指标

- 错误阶段推进率：在状态证据尚不支持子目标完成时，转入后续阶段的比例。先定义标签与判据。
- 干扰后恢复成功率：分母为全部预定义有效扰动试次，另报失败后条件恢复率及对应分母。
- 修正时延：从可观测执行偏离到状态估计/动作选择被正确修正的时间。
- 无扰动成功率与无关扰动误修正率：防止为了重试而破坏正常执行。
- 动作结果预测的动作依赖：屏蔽/打乱实际动作时预测与闭环如何变化。该测试是诊断，不足以单独证明因果理解；需要时用同状态仿真分支检验不同动作后果。
- 延迟与计算：p50/p95、调用数、任务完成时间；仿真暂停等待推理不能支撑真实反应速度结论。

状态探针或漂亮预测图只是辅助；更准确的特征预测必须落实为更正确的闭环行为。

## 6. 三个实现风险需要在训练前堵住

1. **因果信息路径**：预测新观测的 P 不能读取新观测目标；未来教师只能作 loss。未来纯噪声分支应检查全部条件和 VAE 时域感受野，确保没有旁路读取真实未来。正常 flow matching 使用带噪目标不是本身就泄漏；问题是能否支撑“仅凭历史预测”的特定主张。
2. **实际执行与计划不同**：记录真实消费的动作前缀、时间与 episode reset。发送命令不等于关节已到达；实际关节状态应一并参与更新。不能把未执行的计划当成反馈。
3. **结果预测与普通世界流不同**：保留现有单向 world→action MoT 时，专用 P 可以负责动作条件结果预测；不能声称原视频流已经具备任意动作反事实仿真能力。固定 latent tokens 也不能未经验证就称为对象槽或校准的 belief distribution。

## 7. RA-L 投稿定位

[RA-L 官方作者说明](https://www.ieee-ras.org/publications/ra-l/ra-l-information-for-authors/)强调及时、简洁的创新研究思想与应用结果，范围包括显著理论发现及应用案例。篇幅通常为 6 页，最多 8 页（包含相应超页安排）。这支持把一个清楚的机器人问题和完整证据写成紧凑论文；不意味着把已有组件拼起来即可投稿。

建议主张：**在部分可观测长程操作中，使用实际执行动作的结果预测与新观测来修正递归状态记忆，减少任务阶段误推进，并在等数据和近似等计算下改善扰动后的继续执行。**

DINO、首帧 anchor、Wan 和未来语义 loss 作为实现与控制表征组件，不各自声称一项新贡献。标题可暂写为 *Execution-Feedback State Correction for Memory-Augmented World–Action Models*，仅为工作标题。

投稿判断分界：

- 只有设计：尚不能判断达到投稿质量。
- 完整模型涨分，但没有 B2 或可靠记忆近邻：新颖性与归因不足，我倾向弱拒。
- 相同数据/预算下稳定超过普通循环记忆，机制指标改善，并有迁移或真机支持：具备合理 RA-L 投稿基础。
- 仅成功示范、没有真实偏离测试：应把主张收窄到历史状态表征与长程控制，暂不声称可靠失败恢复。

不必为 RA-L 追求全榜第一，也不必把额外大规模动作预训练列为前置条件；需要的是重要问题、可区分的贡献和充分证据。Wan 与 DINO 已含外部预训练知识，应明确披露。

## 8. 对当前时间约束的建议

先按已定 V2 集中实现一个完整候选版本，并在设计时预留 B1/B2 的配置开关和相同数据采样路径。训练过程中保留少量闭环检查，完整版本有效后补必要对照和近邻。不要在这一轮同时增加完整 4D、VLM planner 与 RL。

真正决定是否继续投入论文的是 B3 对 B2 的差异，以及这个差异能否在真实执行偏离后复现。若差异消失，应把 V2 作为有效工程增强，调整论文主张，不继续用更多组件掩盖这一结果。

本轮只新增审稿分析文档与配套 canvas；未修改训练或机器人执行代码，未启动训练或真实运动。
