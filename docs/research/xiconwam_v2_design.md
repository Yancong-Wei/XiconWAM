# XiconWAM V2 设计建议

日期：2026-11-09。用户资源：4～8 张 H20。状态：设计，未实现、未训练；数字是起始配置，不是性能结论。

## 版本决策

保留 Wan2.2-TI2V-5B、现有 MoT、14D joint 控制和 48D 内部接口。新增 DINOv3 空间条件、循环状态记忆、动作结果预测和未来语义监督。直接形成一个完整候选版本；不开展大量小组合搜索。第一版不新增深度传感器输入、完整 4D 重建、VLM planner、RL 或候选动作重排。

## 结构

- 冻结 DINOv3 ViT-B/16，逐相机提 patch；每相机固定池化到 4×4 网格，共 48 个空间 tokens。添加视角、空间位置、时间间隔编码。固定冻结教师输出作为监督目标，防止目标编码器塌缩。
- 将当前空间特征投影到 512 维；episode 首次观测压缩为 16 个 anchor tokens，episode 内保持不变。
- 状态记忆使用 32×512 tokens、4 层轻量 Transformer 更新器。输入旧记忆、当前 48 个空间 tokens、当前 proprio、实际执行动作前缀、观测间时间差和预测残差。只在获得一次新观测时更新一次；不能在每次扩散去噪时反复更新。
- 轻量动作结果预测器 P 根据上一观测/记忆、上一 proprio、实际执行动作前缀与时间差预测当前 DINO 空间特征。将预测与当前观察比较，残差交给记忆更新器学习使用。P 不接收作为目标的当前图像或当前特征。
- P 的输入动作支持可变前缀长度和有效性 mask；不能把完整的未执行 action chunk 当成已执行。eval 端须保存或确认实际消费的前缀，若环境提前终止不能把剩余动作视为执行完成。
- 当前 48 + 状态记忆 32 + anchor 16 = 96 个额外条件 tokens；分别投影到现有 cross-attention context 维度。世界流和动作流都能读，保留现有 MoT 世界到动作的注意力结构。proprio 继续使用原专用编码。
- 在世界流中后层接训练期语义预测头，以 4、16、32 action ticks 的时间查询预测对应未来冻结 DINO 特征；查询读取因果历史条件和世界流 hidden，不读取真实未来教师特征。时间间隔作为明确输入。
- 三相机 RGB 仍走原 Wan VAE；原未来视频 flow loss 保留。预测 32 个动作，部署初始执行前 8 步，再接收观测。10 次联合去噪先沿用，不在此版本同时做一步蒸馏。

残差不等于失败概率；视觉变化可能来自光照或腕部相机运动。仅供学习的状态更新器使用，不直接以阈值触发安全或成功判定。记忆保存当前状态估计，anchor 保存初始线索，预测结果不直接写成已确认事实。32 个 latent tokens 不能在没有验证时称为对象槽位或完整 belief distribution。

## 数据与时序训练

现有随机单窗口不能直接训练持久记忆。新增 episode 连续采样：初始 anchor；最多 8 个按一秒间隔采样的历史观测作 burn-in；随后 4 个连续决策窗口，起点相隔 8 action ticks，每窗口监督未来 32 ticks。秒数由数据实际 fps/timestamps 转换。

burn-in 只运行轻量空间/记忆模块，不反传早期序列；后续 4 个窗口执行截断 BPTT，并对每个窗口计算策略监督。每个决策只能读取该时刻及之前的数据；窗口之间有重叠未来监督是允许的，但真实未来特征不能进入历史条件。短 episode、缺失历史、末尾 padding 均使用 mask。

DINO 特征按实际采样帧离线缓存池化结果；预先估算磁盘开销，避免缓存原始全 patch 多层特征。训练与部署绑定教师权重、图像预处理、相机顺序和时间编码。

正常记忆与陈旧/缺失记忆混合训练。建议 20% 序列使用空/丢帧/更早历史形成的陈旧记忆，其余条件与监督保持一致。不要把来自未来的信息用作历史扰动；不把这种增强宣称为真实抓空、滑落或反事实物理数据。

## 目标与一次训练的起始配置

总损失：L_action + 0.5 L_video + 0.1 L_future_semantic + 0.1 L_action_effect。辅助目标均按有效 token 数均值归一化，DINO 特征归一化，教师 stop-gradient。动作损失保留维度与时间 padding mask。

25% 的训练样本固定未来视频噪声 sigma=1，其余沿用原 flow 噪声采样。未来语义损失只在这部分纯噪声样本上计算，从而不能直接读取含真实未来信号的输入；这些样本依然训练视频和动作 flow 目标。动作噪声继续独立采样。

初始总预算 40k optimizer updates：前 2k 冻结 Wan、训练新增模块及动作专家；后 38k 解冻 Wan 后 10 个 blocks，其余保持冻结。视频解冻部分 lr=1e-5；动作专家及新增模块 lr=1e-4。VAE、T5、DINO 保持冻结。bf16、ZeRO-2、梯度检查点。该预算需按吞吐和闭环收敛调整，不能当成充分训练保证。

全局监督窗口数先取约 128/update：8 卡×每卡 1 序列×4 窗口×累积4；4 卡同配置累积8。这是预算示例，尚未验证显存可行性；先以短跑测显存和梯度连通，再正式训练。连续窗口的有效独立样本数不能与随机 128 窗口等同。

## 实现范围

1. 新增空间特征提取/缓存模块、memory 模块、动作结果预测器和未来语义头。
2. launch 与 model config 新增 mot_memory 架构入口，保留 mot 兼容性。
3. dataset 新增 episode 序列与 burn-in 采样，统一输出历史、执行前缀、时间间隔和有效性 mask。
4. objective/StreamMixer 注入记忆条件并提供世界流 hidden；显式实现纯噪声语义监督分支。
5. trainer 支持序列内记忆状态与截断梯度；优化器覆盖所有新增模块，checkpoint 保存模型结构、教师标识和训练阶段。
6. eval 与 deployment 以 session 管理记忆/anchor/上一状态及实际动作前缀；reset 清空、不同 episode 隔离，同一次观测的重复请求幂等。

## 必要验收与边界

只保留必要检查：时序无泄漏；reset 隔离；实际执行动作前缀正确；新增模块有梯度、冻结模块无更新；训练与服务相机/时间/状态归一化一致。评测读取训练 run 的完整 config；旧模型不能静默当新架构加载。

训练期间保留少量代表性闭环任务监控，候选 checkpoint 做官方完整评测。论文阶段再补最少两个消融：不读历史记忆、更新器不读动作预测残差。它们不是当前开展大量小实验的前置条件。

如果只有成功示范，动作结果预测和状态更新可以训练，但真实失败后的恢复能力没有充分监督；可靠恢复需要额外训练分布中的失败/恢复经验。残差增强不能替代物理失败数据。该方案主要瞄准 Memory、Long-horizon 和部分视觉泛化，不承诺解决 Open 类推理与所有接触精度问题，也不承诺顶会新颖性或具体分数。
